# 云合 RAIN–HEAT 多场耦合互动调度游戏

面向能源与环境专业学生、微电网学习者和项目展示观众的三轮调度小游戏。玩家在晴天、强降雨和回灌压差预警情景中，为地热 ORC、光伏辅助电、雨水分质利用、尾水梯级用热、回灌保护和微水力旁通做运行选择。

## 在线体验

GitHub Pages 发布地址：<https://chrischan-coder.github.io/carbon-footprint/>

## 项目内容

- `index.html`：云合调度员小游戏，含系统流程图、策略选择、计分和复盘。
- `carbon-footprint.html`：日常碳足迹估算网页。
- `app.js`、`app.json`、`app.wxss`、`pages/index/`：微信小程序页面代码。

## 设计边界

游戏沿用云合方案中的概念架构：地热 ORC 为连续主电源，光伏优先支撑辅助负荷，雨水经弃流、过滤、储存后分质使用，尾水按温度梯级利用，回灌根据水质和压差管理，微水力只作少量辅助回收并保留全通径旁通。游戏指数仅用于教学推演，不是现场实测值、施工设计或电站性能预测。
